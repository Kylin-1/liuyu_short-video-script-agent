# 需求说明

## 用户与目标

本项目面向需要制作商品带货、到店引流和活动推广视频的创作者。输入制作需求、素材和品牌规则，输出有事实依据、满足时长上限、可继续编辑的中文脚本。

产品、门店与活动统一使用“主体—事实—操作—画面—来源”结构描述。生成流程结合商业目标、受众和内容形式组织情节，并将产品主张关联到提供的素材。

## 输入

| 类别 | 内容 | 处理方式 |
| --- | --- | --- |
| 基础需求 | 主题、受众、平台、目标时长、风格 | 必填检查及字段标准化 |
| 商业意图 | 购买、到店、报名等目标；演示、教程、剧情等形式 | 目标与形式分别建模 |
| 转化要求 | 行动与承接入口 | 校验两者与商业目标的匹配关系 |
| 素材 | ID、主体、事实原文、操作、画面、来源 | 按主体检索并记录引用 |
| 品牌规则 | 禁用词、必须出现的内容 | 确定性检查 |
| 创意要求 | 可选的场景、开场、转折、结局 | 按锁定或参考策略处理 |

输入支持中文标签文本、Markdown 和 JSON。需求整理保留字段来源；缺失、冲突和歧义进入确认流程。用户无需预先提供完整剧情。

## 输出

最终结果包含任务状态、中文标题、逐镜动作、旁白或字幕、计划与估算时长、起止时间、素材 ID 与原文、拍摄说明和风险。`COMPLETED` 返回最终 `script`；其他状态返回问题及执行记录。

## 成功标准

| 场景 | 验收标准 |
| --- | --- |
| 正常生成 | 输出字段完整，最终版本通过适用检查 |
| 缺关键信息 | 返回 NEEDS_INPUT，列出缺失字段 |
| 无素材 | 补检或请求同主体资料，返回明确状态 |
| 工具失败 | 记录故障，有限重试或结束任务 |
| 超时长 | 依据估时结果修订并复检，或返回 DURATION_UNMET |
| 事实追溯 | 产品主张关联素材 ID 和支持它的原文 |
| 动态决策 | 模型根据工具观察选择下一步动作或结束 |
| 执行预算 | 步数、工具调用和修订次数有界，耗尽时返回未完成状态 |

## 实现范围

交付形式为 Python CLI，覆盖需求整理、脚本生成、分镜规划、检查、修订与 Trace。视频生成、配音、剪辑及投放属于下游制作流程。各验收项的当前结果见 [效果评估](03-evaluation.md)。
